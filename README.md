# One Letter for Your Day

Entry for the make.fun competition "One Letter for Your Day"
(`u-puan-one-letter-for-your-day-e54e9c36`).

`main.py` writes exactly one letter to `/output/entry.txt` — a single
character, nothing else.

## The letter: Z

**Z — for "zombie".** A day spent shuffling through on zero sleep: body on
autopilot, brain offline, running on fumes and caffeine. Why Z:

- **Vivid and specific:** "zombie" paints an instant picture — half-awake,
  slow-moving, eyes glazed — not a vague mood.
- **Funny, lands at once:** everyone has had a zombie day, and everyone
  says it the same way.
- **True:** zero sleep is a real, ordinary day, honestly reported.
- **The letter suits the word:** Z *is* the sleep letter (Zzz), and it is
  the first letter of "zombie" — the word anyone reaches for behind Z.

Alternatives considered and passed over: F ("fried" — vivid, but F also
pulls toward Friday/frazzled/foggy, so the association is diffuse), T
("toast" — funny, but a weaker picture than a zombie), W ("wrecked" /
"wired" — strong, but the letter doesn't fit either word as tightly as Z
fits zombie).

## How to run

```sh
python3 main.py
```

This creates `/output/entry.txt` containing the single byte `Z` (no
trailing newline). Python 3.13, standard library only, no network.
